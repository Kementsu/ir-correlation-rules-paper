# Reference articles

`docs/refs/` is the working folder for the source articles used to transcribe
`rules/rules_draft.csv` and `rules/rules_frozen.csv`. Its contents are not
redistributed: everything in this directory except this file is excluded from
version control.

The rules were transcribed from the twelve Brian C. Smith articles in
*Spectroscopy* listed in `docs/rules_draft_notes.md` (the five "Big Review"
summaries and the columns on benzene rings, alkenes, alkynes, aldehydes,
nitriles, nitro groups and amine salts), read on spectroscopyonline.com. The
`rules_frozen.csv` table records, for every rule, the article, the table and
the page it came from.

Coates, J., "Interpretation of Infrared Spectra, A Practical Approach",
*Encyclopedia of Analytical Chemistry*, Wiley, 2000, was not available to us
and is not part of the frozen rule set; a comparison with its tables would be
a separate, dated addendum (see `docs/decisions_freeze.md`, D12).
