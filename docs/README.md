# Documentation

Working documents of the study, in the order they were written. Dates are in
the files.

| File | What it is |
| --- | --- |
| `DOWNLOAD.md` | How to obtain the Chemotion archive and the NIST spectra (`data/raw/` is not tracked). |
| `inventory.md`, `inventory_nist.md` | Generated summaries of the two collections after quality control. |
| `rules_draft_notes.md` | How the rule tables were transcribed from the source articles, and what was left out. |
| `decisions_freeze.md` | The twelve decisions taken to freeze the rule table, each with the alternative rejected. |
| `preregistration.md` | The analysis plan and the four hypotheses, written before the confirmatory run. |
| `pipeline_notes.md` | Fixed processing choices and what the development-split check showed. |
| `rule_metrics_dev.md` | Development-split run (pipeline check; not a result). |
| `rule_metrics_confirm.md` | Confirmatory run on Chemotion, one row per rule and definition. |
| `nist_replication_plan.md` | Selection rules for the NIST replication set, written before it was scored. |
| `rule_metrics_nist_confirm.md` | Replication run on NIST. |
| `results_first_read.md`, `results_nist_replication.md` | First reading of the two runs, the basis of the Results section. |
| `refs/` | Source articles (not tracked); see `refs/PENDING.md`. |
