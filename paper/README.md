# Manuscript

LaTeX sources of the article. Build with

```sh
cd paper
latexmk -pdf main.tex
```

or upload the folder to Overleaf. `figures/` and `tables/` are generated by
`scripts/figures.py` and `scripts/tables.py` from the result tables in
`data/processed/`; do not edit them by hand. `figures/figure_numbers.md` lists
every number quoted in the figure captions and in the text, with the script
that produced it.
